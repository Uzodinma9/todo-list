# My To-Do List

A simple and responsive To-Do List web application built using HTML, CSS, and vanilla JavaScript.

## Features

- Add tasks
- Mark tasks as completed
- Delete tasks
- Press Enter to add tasks
- Prevent empty tasks
- Show total, completed, and remaining tasks
- Clear completed tasks
- Save tasks using browser localStorage
- Responsive design for desktop and mobile

## Technologies Used

- HTML
- CSS
- Vanilla JavaScript
- Browser localStorage
